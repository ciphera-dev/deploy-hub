Le panneau

Tout se pilote depuis le navigateur

Projets, déploiements, domaines, variables et équipe, avec les journaux de build et d'exécution en direct.

  1. 01 · Installer

    Une commande sur votre serveur

    L'installeur vérifie la signature minisign puis le SHA-256 avant d'installer quoi que ce soit, puis affiche l'adresse de l'assistant (valable 24 heures).

    signature minisignvérifiée

  2. 02 · Connecter GitHub

    La GitHub App, créée depuis le panneau

    Créez le premier compte dans l'assistant, puis la GitHub App depuis Connecteurs, et reliez un dépôt à un projet.

    Connecteurs › GitHubGitHub App

  3. 03 · Déployer

    Chaque push devient un déploiement

    Build Railpack, Dockerfile ou Compose suivi en direct ; le proxy obtient le certificat Let's Encrypt du domaine.

    app.example.comHTTPS

Fonctionnalités

Tout ce qu'il faut pour déployer,
rien de superflu

Un seul binaire pour le plan de contrôle, qui sert aussi le panneau web. Un proxy Pingora avec certificats Let's Encrypt. Des builds BuildKit.

Déploiement

Projets reliés à un dépôt GitHub, déploiement à chaque push ou manuel, deploy hooks à expiration, annulation et rollback.

Builds

Railpack sans configuration, Dockerfile ou Compose. Un buildkitd isolé par projet, avec limites de taille, de mémoire et de durée.

Domaines et HTTPS

Domaines par projet avec vérification, certificats Let's Encrypt émis et renouvelés par le proxy, domaine dédié au panneau avec HSTS.

Variables et secrets

Variables par projet et par environnement, import .env, variables globales. Secrets chiffrés avec age, jamais renvoyés par l'API.

Suivi

Vue d'ensemble, métriques des nœuds, historique des déploiements, journaux de build et d'exécution en direct.

Équipe et accès

Invitations et rôles, passkeys (WebAuthn), TOTP et codes de secours, liste d'IP autorisées, sessions révocables.

Notifications

E-mails par votre serveur SMTP (connexion chiffrée obligatoire), préférences par membre, avis de sécurité aux propriétaires.

Exploitation

Mise à jour vérifiée avec retour arrière, vérification de nouvelle version désactivée par défaut, sans télémétrie.

Sécurité

Sûr par défaut,
vérifiable de bout en bout

Chaque couche est décrite dans la documentation du dépôt.

  • Releases signéesminisign protège l'installation et les mises à jour ; cosign et l'attestation SLSA permettent l'audit de la provenance.
  • Agent relié en mTLSQUIC avec mTLS obligatoire, PKI propre à l'instance, API étroite : jamais d'exécution arbitraire sur le nœud.
  • Secrets chiffrésChiffrement avec age, champs en écriture seule dans l'API, valeurs masquées dans les journaux.
  • Comptes protégésMots de passe Argon2, passkeys, TOTP, confirmation renforcée des actions sensibles.

Vérifier avant d'installer

Téléchargez le script et sa signature, vérifiez-la avec les clés publiques, lisez le script, puis lancez-le.

  • install.sh script d'installation
  • install.sh.minisig signature minisign
  • install.sh.sha256 empreinte SHA-256
  • ciphera.pub clés publiques de confiance
  • releases/latest.json dernière version, signée
