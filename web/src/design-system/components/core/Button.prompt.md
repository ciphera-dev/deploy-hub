Ciphera button — bordered dark control by default; use filled for full-width card CTAs, ghost for inline card actions.
```jsx
<Button icon="sliders-horizontal">Customize</Button>
<Button variant="filled" size="sm" block iconRight="arrow-right">View Detail</Button>
<Button variant="ghost" icon="message-circle">Ask AI</Button>
```
Variants: secondary | filled | ghost | inverse. Sizes: sm (28px) | md (32px).
